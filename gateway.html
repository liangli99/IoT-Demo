⚙️ Protocol Translation Engine (Binary GATT ➔ JSON)

Asynchronous edge parser converting raw hex telemetry into normalized cloud payloads.
Throughput: ~1,200 msg/min
Step 1: Southbound Ingest Raw BLE GATT Characteristic Byte Stream (Node 01)
1b ff 75 00 01 18 92 01 f4 00 00 03 f6 5e 2a 6e 09 c4 2a 6f 14 50 [UUID: 0x2A6E (Temp)] [Bytes: 09 C4 ➔ 25.00°C] | [UUID: 0x2A6F (Hum)] [Bytes: 14 50 ➔ 52.00%]
Step 2: Python Byte Unpacker (`struct.unpack`) Parser Logic executing in async event loop
temp_raw, hum_raw, batt_raw = struct.unpack("<HHB", payload_bytes[14:19]) temp_celsius = temp_raw / 100.0 # 2500 -> 25.00 °C humidity_pct = hum_raw / 100.0 # 5200 -> 52.00 % battery_pct = batt_raw # 94%
Step 3: Normalized JSON Document Enriched with ISO timestamp, gateway metadata, and RSSI
{ "device_id": "sensor_node_01", "gateway_id": "gw_pi4_bcm2711_01", "temp": 24.85, "humidity": 52.4, "pressure": 1013.25, "battery": 94, "rssi": -64, "timestamp": 1789076000, "protocol": "BLE_5.0_GATT", "status": "NORMAL" }
