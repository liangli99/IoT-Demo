What's Inside

All Five Tiers, Live & Interactive

Every component of the production IoT stack is simulated and visualized in real time — from constrained edge firmware to cloud rules engine.

🎛️
Perception Layer — ESP32 Sensors
Simulates ESP32-WROOM-32 sensor nodes running a 4-phase RTC duty cycle (SLEEP → WAKE → SAMPLE → BROADCAST). Reads DHT22 temperature/humidity, BME280 pressure, and MPU6050 6-axis vibration — all with realistic noise and drift.
ESP32 DHT22 MPU6050 Deep-Sleep
📶
Proximity Network — BLE 5.0
Displays live BLE 5.0 advertisement packets (ADV_IND) from each node, with MAC addresses, RSSI signal strength, and service UUID 0x181A (Environmental Sensing). AES-128 CCM link encryption simulated.
BLE 5.0 IEEE 802.15.1 AES-128 CCM
🖥️
Edge Gateway — Raspberry Pi 4 Model B (4GB)
The Raspberry Pi 4 gateway translates raw BLE GATT frames into structured MQTT JSON payloads. Features store-and-forward: packets are cached in local SQLite during WAN outages and bulk-flushed on reconnect.
Raspberry Pi 4 (4GB) Broadcom BCM2711 bleak + paho SQLite Store-Forward
☁️
AWS IoT Cloud — Rules, Lambda & DynamoDB
Live IoT Rules Engine SQL evaluation, least-privilege X.509 IAM policies, DynamoDB time-series persistence, and AWS Lambda alerts dispatched via SNS when temperature exceeds 30 °C. Full data inspector included.
AWS IoT Core DynamoDB Lambda SNS
❄️
AC Auto-Control — Temperature-Driven
A fully autonomous AC controller monitors sensor temperature and automatically activates the relay actuator (AC compressor) when temp ≥ 26 °C, and disengages at ≤ 24 °C. Configurable thresholds and manual override supported.
Auto-Control Hysteresis SSR Relay PWM Fan
📱
Mobile App — Android-Style Dashboard
A full Android-style single-page app with radial SVG temperature gauge, sensor metric cards, AC control panel with threshold sliders, alert feed, and bottom navigation — styled as a native Material dark-theme app.
Material Design SVG Gauge Bottom Nav Live Charts
