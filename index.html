Bidirectional Actuation & Remote Control Reverse Control Loop

Dispatches actuation commands back down the stack: Web Client → AWS IoT Core (MQTT) → Edge Gateway → BLE GATT Write → Field Hardware (ESP32).
Targeting: Environmental Lab Node (sensor_node_01)

🎛️ Hardware Actuator Switches

💨 Forced-Air Cooling Fan
Actuates 5V PWM fan connected to ESP32 GPIO 18 via MOSFET driver.
PWM Duty: 60%
🔌 Solid-State Circuit Relay (SSR)
Toggles AC/DC load relay connected to GPIO 23 with opto-isolation.
💡 Visual Diagnostic LED Mode
Sets onboard status LED state for field locating and physical debugging.
⏱️ RTC Deep Sleep Interval Setpoint
Configures how long ESP32 stays in ultra-low-power sleep between bursts.
